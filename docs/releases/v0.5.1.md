# KartPad 0.5.1 — Android and iPhone/iPad

**Draft — not published. Release gates and owner approval are pending.**

Planned packages: Android **0.5.1 / code220** and iPhone/iPad
**0.5.1 / build73**. Final source commits, hashes, sizes and audit results will
be recorded after the clean release builds. No new Mac package is currently
included; its existing download remains unchanged.

## Changes

- Android frame delivery and CPU overhead improvements: native-rate FIFO
  presentation, game-thread performance hints on Android 13+, cheaper graphics
  command processing, and display-rate hints.
- Course-specific shader preparation and persistent Android pipeline caching;
  faster guarded DVD reads, decompression and file-handle reuse. Shader stalls
  can still occur.
- RVZ import through Android's file picker.
- Shared runtime stability corrections, including Item Rain, sleep timers,
  depth rendering, input during the exit prompt, and empty-save handling.
- Safer console-identity initialization, preservation of socket send errors,
  orderly fatal shutdown, and validation of compatible game modules.
- Android release command buffers omit diagnostic debug labels. This targets
  the supplied ROG Phone 7S crash stack in #321; it is not yet verified on that
  phone and does not establish a general Adreno fix.
- Physical Android 9/10 devices can use background pipeline workers. The
  affected emulator fallback remains. This addresses one source of stalls in
  #320, but is unverified on the reporter's Huawei phone.
- Android's setting is now named **Touch auto-accelerate** to clarify its scope.
- iPhone/iPad includes the shared runtime improvements with diagnostic mode
  explicitly off. Its native-rate FIFO option remains off by default.

## Updating

Android: install the new release APK over v0.5.0 using the existing public
signing identity. **Do not uninstall or clear app data.** The release APK is
not an in-place replacement for differently signed private development builds.

For iPhone/iPad, use the unsigned IPA with the same compatible signing identity
and bundle identifier as your existing installation. Preserve saves and game
data and update in place. Review the installation guide before changing signing
methods. Game images and the Retro asset pack are not included.

## Verification

Final release-package audits and disposable-emulator Android update-path testing
are pending. The owner waived the code219/build72 play-session gate on

recorded as passed. This draft is not an acceptance record.

Earlier Pixel tests showed improved presentation timing and reduced game CPU
cost in specific controlled scenes. The owner completed a Retro online race on

public-code135 versus release-code220 benchmark, nor validation of other GPUs.

## Known limitations

- Adreno character geometry corruption remains unresolved
  (#104/#193/#211/#316/#308).
- Physical-controller auto-acceleration is not implemented (#319).
- Performance on lower-end phones remains limited. The Android 9/10 worker
  correction does not eliminate the high CPU cost observed in #320.
- Blocking network receives can stall frame production; a roughly one-second
  stall was observed. The existing receive timeout can be longer, so one second
  is not a guaranteed upper bound. A deferred-receive change is not included.
- The #321 and #320 corrections still require affected-device confirmation
  after publication. Notification-related slowdown and background device-loss
  reports are not established as fixed.
- iPad #322 character-selection freeze requires the owner acceptance gate;
  no broad fix claim follows from compilation or diagnostic-mode changes.
